# Security and privacy

This diagnostic package is not a security boundary or approval authority. It cannot authenticate an approver, verify event truth/completeness, stop execution or prove effects. Do not process secrets or use `consistent` to authorize operations. Getters may execute arbitrary code; prefer sanitized JSON values. No dependency audit can prove this package secure.

For a potential vulnerability, use GitHub private vulnerability reporting if enabled on the eventual public repository. Until a verified private channel exists, do not post sensitive details publicly; contact the maintainer through an established private channel. No response SLA is promised. Use synthetic minimal reproductions with no live credentials, tokens, customer identifiers or raw private traces.
