# Contributing

This is an unpublished source candidate. Once its repository is published, use an issue or draft pull request there. Do not open unrelated promotional issues elsewhere.

Use Node20+. No installation is required for runtime tests. Run `npm run check`. Run strict TypeScript against test/types.ts with an approved compiler. Add regression cases for observed failures, fixed output codes and redaction. Preserve exact scope joins, bounded memory, readonly outputs and no IO. Never add automatic repair or approval enforcement to this package.

Use synthetic metadata only. Do not attach transcripts, customer identifiers, approval tokens or secrets. Explain original work and upstream licenses. AI-assisted contributions must be honestly described where project policy requires it; a human reviewer must inspect meaningful behavioral changes. Require independent review and exact-commit CI before release. Do not promise a response time.
